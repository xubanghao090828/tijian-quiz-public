# 原刷题界面的题干高亮预览

地址：https://xubanghao090828.github.io/tijian-quiz-public/previews/highlight/

这是基于原刷题页面的独立交互预览，尚未接入正式刷题页或 APK。原有 HTML、CSS、字体、按钮和切题动画直接复用；只给题干增加高亮交互，并在页面最底部增加默认收起的设置。

- 在题干内直接横向划选，纵向滑动保留页面滚动；鼠标拖动也可使用。
- 可比较荧光底纹、文字变色、底纹加变色三种效果及三种颜色。
- “保存新高亮”决定接下来新划的内容是否写入本机预览历史。切换开关不会删除已保存记录；换题或刷新清除临时内容。
- 同一次圈画可有多笔；点击“新建一次”或重新进入题目，可开始另一份记录。
- “显示历史高亮”只控制可见性。历史列表先展示选中记录的题干预览，点“显示这次高亮”才应用；取消不改变主题干。
- 两份明确标注的演示记录用于试用。自己保存的预览记录与正式答题数据隔离，使用独立的预览存储命名空间，仅保存在这个浏览器。
- 预览保留原刷题按钮供试用，答题只写入独立预览空间；不访问同步接口，不修改正式题库、答题次数、错题或已有同步内容。正式跨设备圈画同步、APK 和多视图接入在样式确认后实施。

## 现成组件评估

截至 2026-11-18，最多选择以下三个候选：

| 项目 | 维护与使用参考 | 可复用与需要适配的部分 | 决策 |
| --- | --- | --- | --- |
| [web-highlighter](https://github.com/alienzhou/web-highlighter) | 约 991 stars；最近推送 2026-10-29；MIT；无运行时外部依赖 | 可直接复用 Range 高亮、包装元素恢复/清理 API；手指直接涂画、按题保存和版本预览需要接入层 | 采用固定 0.8.0 浏览器发行版。保留全部许可证、包完整性与来源信息。比从零实现重叠 Range 和 DOM 恢复更易维护，兼容范围较广。 |
| [Clean Selection](https://github.com/cleanselection/cleanselection) | 当前 0 stars；最近推送 2026-09-07；MIT；浏览器脚本 | 直接涂画手势很接近需求，但公开 SelectionState 主要输出文本预览、片段索引和几何位置；缺少可直接用于题目历史版本恢复的稳定文本锚定 API | 不引入第二套画布、弹窗和动画生命周期。小项目的真实部署积累与长期稳定性仍需验证。 |
| [penciled](https://github.com/marcellosso/penciled) | 约 22 stars；最近推送 2026-11-04；MIT；依赖 @floating-ui/dom | 自带存储适配器、工具栏和重定位；不修改题干 DOM。需 CSS Custom Highlight API，旧内核不提供回退 | 直接采用会提高浏览器最低要求，并引入一套额外 UI。作为后续现代内核方案保留。 |

预览采用成熟 Range 核心加小范围触摸适配：只给当前题干建立字形坐标，移动期间按帧绘制连续选区，松手再生成持久高亮。跨行时按文字起止位置选取，避免对角轨迹误选邻行文字；不运行空闲动画循环。保存相对于原题干的 UTF-16 起止位置和原文校验，字体、换行或屏幕尺寸变化不改变锚点。以后正式接入时仍需处理题干替换、多个视图生命周期、手势协调及同步冲突。
