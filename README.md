# 题间

数控题库刷题网页与荣耀 Android 应用。内置 1,460 道题及解析，可离线刷题，无需登录。

## 1.23.1 离线首页计数修正

合并或恢复后，首次离线打开立即重建并刷新首页的答题次数、错题数和正确率，无需等待联网。

## 1.23.0 扫码配对与双端记录合并

我的空间提供十分钟临时码、二维码、扫码或图片识别；原设备核对四位数字后允许连接，新设备先查看合并预览，再自动备份并合并两边记录。答题事件按唯一编号去重，历史轮次合并；同轮同题不同答案保留双方版本，在“同步冲突”中查看。设备独立凭证、命名、最近连接与单独解绑；备份可下载、导入和恢复为独立空间。

两台都升级后：原设备生成临时码 → 另一台扫码/输入 → 原设备允许 → 另一台确认备份并合并。覆盖安装，不要先卸载。离线继续刷题，联网同步；旧长配对码兼容。各设备设置各自保留，自导入题库暂不自动跨设备传输。

## 1.22.0 Motion 动效重做

复用 [Motion](https://github.com/motiondivision/motion) 的免费 JS 引擎（MIT），用短位移弹簧交接原位按钮和底部胶囊。切题采用分段淡化与短位移，避免新旧文字重叠，取消长解析的深复制；支持中断、快速点击与减少动态效果。依赖随应用离线内置，原许可证和来源见 vendor/motion-LICENSE.txt、motion-SOURCE.txt。

## 1.21.0 紧凑答题页与滑动操作栏

手机刷题页压缩顶部装饰和重复信息，把空间留给题干和四个选项。切题栏在页底和选项下方之间随滚动滑动，阅读解析时可随时切题；返回后恢复主导航。保留每题记录、计时、字号设置和多指操作。

## 1.20.0 计时与多指操作

计时收起在题卡底部，点开可看。题目显示累计做题/答错次数、最近一次结果和最近五次对错。

记录本轮和本题的实际刷题用时，离开答题页或切后台自动暂停，历史、总结与回顾可查看。三指左右切题、四指轻点标记、五指轻点题号导航，均可在设置关闭。使用离线内置的 [Hammer.js](https://github.com/hammerjs/hammer.js) 触摸输入层，保留 MIT 许可证。用时支持跨设备合并和重复同步去重，旧记录不推算历史用时。

## 1.19.0 全局字体与应用内切换

默认使用用户提供的印品鸿蒙体，覆盖导航、刷题、解析与结算。设置中可即时切换绝区零字体或系统字体，预览效果并保存到本机。字体内置于 APK 并纳入网页离线缓存。

## 1.18.0 更清晰的切题与增强震感

切题过渡延长至 280 毫秒并增加位移。新增默认开启的增强震感，延长反馈脉冲并提高答对和切题力度，答错默认震两下；可打开安卓声音设置检查系统触感。保留已有震动偏好，新安装默认强度为 90%。

## 1.17.0 安卓震动与快速切题

新增震动强度滑杆、答对与答错的独立节奏和试震，默认答错震动两下。切题轻震可单独关闭，设置保存在本机。支持强度控制的安卓马达使用原生振幅；其他设备通过时长与节奏适配。包含 120 毫秒切题交叠过渡。

## 1.16.0 切题过渡

手动与自动切题使用 120 毫秒交叠过渡。外框和进度栏稳定，内容同步移动，上一题采用反方向。支持快速连点、同步刷新协调以及动效开关。

## 1.15.0 顺序范围与薄弱分类强化

可指定顺序刷的起点并独立续做。总结提供本轮范围、连续完成、漏答、每 50 题分段和全部分类表现，并可补最早未答题。从错题知识分类抽取最多 50 道组成强化卷，优先同分类未出现题，保留得分、历史和整卷回顾。

## 1.14.0 记忆复习

采用 [ts-fsrs 6.0.0 / FSRS-7](https://github.com/open-spaced-repetition/ts-fsrs) 的官方默认参数，在本机离线安排复习。错题答对后继续保留，提供到期、待巩固、已巩固和久未练筛选；到期队列每轮最多 30 道。短间隔重学题优先，已巩固题也会按时返回。

同题跨来源分组共享记忆进度。复习事件保存时间与评分，用于离线恢复和跨设备同步。旧题从本次升级起建立计划，当前没有训练个人专属模型参数。

浏览器包与依赖许可证位于网页资源的 vendor/fsrs-LICENSE.txt。

## 1.13.0

答对后自动进入下一道未答题，答错时停留看解析，可在设置关闭自动下一题。错题本按来源模式分组，各组可搜索、复习和独立移出；旧记录无法识别来源时保留在历史未分类。

## 1.12.0

整库顺序刷会记录答案和停留题号，重新打开可继续。所有模式都有阶段总结与完成结算，支持错题、标记题、逐题和整卷回顾。整卷每页展开 10 道题及其答案解析。

题目导入支持 Excel、CSV、TSV、JSON 和粘贴文本，预览查重后确认追加。

手机与网页在「我的空间」使用相同配对码可同步学习记录。不同人使用各自的配对码。
